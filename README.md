# 3D Point Rotation

A simple C++ console-based 3D point renderer that projects 3D coordinates onto a 2D terminal screen and continuously rotates them around the Y-axis.

## Features
- 3D-to-2D perspective projection
- Point rotation
- Real-time terminal rendering
- Adjustable camera distance and rotation speed

## Build & Run
Compile the source files with a C++ compiler:

```bash
g++ main.cpp Canvas.cpp -o renderer
./renderer
```

Press `Ctrl+C` to stop the animation.
